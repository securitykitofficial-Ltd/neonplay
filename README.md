# 🎮 NeonPlay

NeonPlay is a lightweight, zero-backend HTML5 web gaming platform where users can play instant browser games without any downloads or installations.

## 🚀 Features
* **Instant Gaming:** Play popular HTML5 games directly in your browser.
* **Responsive Design:** Optimized for both mobile and desktop screens.
* **Zero-Backend Architecture:** Built with pure HTML5, CSS3, and JavaScript, making it fast and easy to host.
* **Essential Legal Pages:** Includes Privacy Policy and Terms of Service for ad-network compliance (e.g., GameMonetize).

## 📁 File Structure
- `index.html` - Main homepage & game catalog
- `about.html` - About Us page
- `privacy.html` - Privacy Policy page
- `terms.html` - Terms of Service page
- `robots.txt` - SEO crawler instructions
- `script.js` - Dynamic game loader and logic
- `styles.css` - Custom styling and responsive layout
